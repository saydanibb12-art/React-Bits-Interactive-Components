# ⚛️ React Bits – Interactive Components

A collection of modern, reusable, and interactive UI components built using React.js. This project explores creative animations, stylish designs, and reusable frontend elements to create engaging web experiences.

## 🚀 Features

- Modern and interactive UI components
- Smooth animations and transitions
- Reusable React components
- Responsive design
- Creative visual effects
- Clean and organized code structure

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## 💻 Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/saydanibb12-art/React-Bits-Interactive-Components.git
```

### 2. Navigate to the project folder

```bash
cd React-Bits-Interactive-Components
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

### 5. Open in browser

Visit the local URL displayed in your terminal.
